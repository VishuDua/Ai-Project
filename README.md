The issue can be as small as asking for documentation of a particular functionality where its missing, or as big as identifying a critical bug, requesting a new feature, asking clarifying questions, etc.

The fix can be as small as adding documentation or as big as fixing a critical bug.
The goal here is for you to learn how to fork, merge, create issues and use github through UI and the terminal.
